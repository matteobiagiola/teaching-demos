1. **Activation trace**: python activation_traces.py. The AT at fc1 has 128 values. The distance between the ATs of the two 7s (13.24) is smaller than the distance between a 7 and the 1 (48.01).

2. **LSA and DSA in 2D**: python toy_2d.py. LSA = -log(density of the predicted class). DSA = dist_a / dist_b. Compare the "far away" test input (high LSA, DSA less than 1) with the "misclassified" test input (high LSA, DSA more than 1). LSA measures how rare an input is. DSA measures how near an input is to the boundary between classes.

3. **SA guides selection of individual inputs (MNIST)**: python main.py --sa lsa. Show sa_low_and_high_lsa_fc1.png: only 2 of the 10 inputs with the highest LSA are misclassified. The others are unusual digits with a correct prediction, as the "far away" input. SA gives a value to each test input, so it can guide the selection of individual inputs. Then show the plots of DSA: sa_low_and_high_dsa_fc1.png (6 of the 10 inputs with the highest DSA are misclassified) and sa_misclassified_dsa_fc1.png. 
SA correlates with the likelihood that an input reveals a problem: the 1,000 inputs with the highest DSA contain 88 of the 91 misclassified inputs, and each of the other groups contains at most 1.

4. **Changing layer**: Show the effect of the layer with the results of DSA at conv1: sa_misclassified_dsa_conv1.png and sa_misclassified_dsa_fc1.png. The 1,000 inputs with the highest DSA contain 88 of the 91 misclassified inputs at fc1, but only 35 at conv1. The layer decides what "surprising" means. conv1 finds strokes and edges, which all the digits have: the classes are not separated, and SA shows unusual strokes. fc1 (the last hidden layer) shows which digit the network sees: the classes are separated, and SA shows inputs that are unusual for the predicted digit.

5. **Suprise covereage**: sc_dsa_fc1.png. First subfigure: SC changes with the test set, with the same U and n. 100 random inputs give 7.70%, 1,000 give 30.80%, and 10,000 give 51.90%. 1,000 inputs of only the digit 1 give 20.90% (less diverse). The other two subfigures: the same test set gives an SC from 0.00% to 87.30% for different U, and from 80.00% to 30.88% for different n.
